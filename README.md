# Allen Moncey Varghese — portfolio

Static site (plain HTML, CSS and JavaScript, no build step) served by GitHub Pages at https://allenmoncey.github.io/.

- `index.html` — home: projects, industry results, publications, contact
- `about.html` — experience, education, skills, honors
- `resume.html` and `Allen_Moncey_Varghese_Resume.pdf` — resume (the PDF is printed from `resume.html`)
- One page per project: `sensor-codec`, `audio-autoencoder`, `meltio-robotics`, `tooth-inspection`, `digital-twin`, `machining-doe`, `seir-simulator`
- `links.js` — code repository URL for each project page; a "Code on GitHub" link appears on a page once its URL is set
- `style.css`, `main.js`, `favicon.svg`, `og-image.png`, `404.html`

Preview locally with `python -m http.server` and open http://localhost:8000.
